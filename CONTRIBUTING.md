# Contributing

Thanks for helping. This repository is generated from the lessons and problems
on [bytepatterns.com](https://bytepatterns.com), so the fastest route for a fix is an issue:

1. Name the file, for example `sorting/02-bubble-sort.py`.
2. Say what you ran and what you expected (`python run_all.py` output helps).
3. For a wrong answer or a missed edge case, include the smallest input that
   shows it.

Pull requests are welcome as a way to show a fix. We apply it to the lesson on
the site and regenerate this repository, so your change arrives through the
next build rather than a direct merge. Please keep to the house style: standard
library only, short functions, comments that explain why rather than what.

New algorithms start as lessons on the site. Suggest one in an issue.
