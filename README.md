# BytePatterns Algorithms

**Every algorithm from [bytepatterns.com](https://bytepatterns.com?utm_source=github&utm_medium=readme&utm_campaign=algorithms) as a small Python file you can run, read and break.**

![lessons](https://img.shields.io/badge/lessons-324-0a7cf5) ![runnable files](https://img.shields.io/badge/runnable_files-566-0a7cf5) ![problems](https://img.shields.io/badge/problems-330-0a7cf5) ![license](https://img.shields.io/badge/license-MIT-green) ![python](https://img.shields.io/badge/python-3.9%2B_%C2%B7_no_deps-3776ab) [![run-all](https://github.com/bytepatterns/algorithms/actions/workflows/run-all.yml/badge.svg)](https://github.com/bytepatterns/algorithms/actions/workflows/run-all.yml)

236 lesson files across 26 modules, plus 330 practice-problem solutions. Every file is standalone, uses only the standard library, and asserts the output its lesson promises.

## Watch it, then run it

1. **Watch** the lesson on [bytepatterns.com](https://bytepatterns.com?utm_source=github&utm_medium=readme&utm_campaign=algorithms): a step-by-step animation you control, a short explanation, an exercise and a quiz. Many lessons also have a [short video](videos/README.md).
2. **Run** the same code here. It is copied from the lesson, not rewritten, so what you saw is what you run.
3. **Break it.** Change a comparison, flip a pointer, run it again and watch the check fail.

```console
$ python sorting/02-bubble-sort.py
[1, 2, 4, 5]
```

Each file opens with the lesson's idea and a link back to its animation. The example at the bottom runs under `if __name__ == "__main__":`, so you can also import any file and reuse its functions.

## Run it

You need Python 3.9 or newer. Nothing to install.

```bash
git clone https://github.com/bytepatterns/algorithms.git
cd algorithms
python sorting/02-bubble-sort.py
```

Run everything, or only one folder:

```bash
python run_all.py
python run_all.py graphs
```

`run_all.py` runs each file in its own process and prints a red `FAIL` with the reason for anything that raises or no longer matches its lesson. CI runs it on Python 3.11 and 3.12 for every push.
